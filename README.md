# Week3-customer-segmentation
Customer segmentation using K-Means clustering 
Customer Segmentation Using K-Means Clustering
Project Overview

This project focuses on customer segmentation using unsupervised machine learning. The K-Means clustering algorithm is used to group customers based on their annual income and spending score.

Objectives
Analyze customer data using Python.
Perform data cleaning and check missing values.
Conduct Exploratory Data Analysis (EDA) using graphs.
Apply feature scaling using StandardScaler.
Select the number of clusters using the Elbow Method and Silhouette Score.
Train a K-Means clustering model.
Visualize and interpret customer segments.
Dataset

The project uses the Mall Customer Segmentation dataset, which contains customer information such as age, gender, annual income, and spending score.

Dataset source: https://github.com/hannazan/mall-customer-segmentation

Technologies Used
Python
Google Colab
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Project Workflow
Import required libraries.
Load the dataset.
Inspect and clean the data.
Check missing values and duplicates.
Perform Exploratory Data Analysis (EDA).
Select features and apply StandardScaler.
Use the Elbow Method and Silhouette Score to investigate the number of clusters.
Train the K-Means clustering model.
Evaluate the model and analyze cluster profiles.
Interpret the customer segments.
Results

The K-Means model groups customers according to similarities in annual income and spending score. The resulting clusters can help identify different customer profiles and explore potential marketing strategies.

The final number of clusters and evaluation results are documented in the Jupyter Notebook.

How to Run

Open the .ipynb notebook in Google Colab.
Run the code cells in order.
Review the generated graphs, cluster assignments, and evaluation metrics.

Conclusion

This project demonstrates how unsupervised machine learning can be used to segment customers. The results provide insights into customer profiles and may support data-driven marketing decisions.
